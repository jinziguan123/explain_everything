## Follow-up #4 — splash "加载 theory cache" 改 "检查 theory cache"

**根因**: `splash_screen.py:56` INIT_STEPS[2].label = "加载 theory cache", 但 `_load_theory_cache` (line 172-183) 调 `get_active_theories(storage, embedder=None)` — embedder=None 时只走 stale-cache fallback (不能 recompute, 因 recompute 必须用 embedder). UI 标 "加载" + ✓ 给 user false sense 真在加载, 实际是 no-op 检查.

**修法**: INIT_STEPS[2].label 改 "检查 theory cache" (1 char change).

**Files**: `src/explain_engine/chat/splash_screen.py` line 56.

**Test**: 加 1 test `tests/test_splash_screen.py::test_init_steps_label_check_theory_cache` (或 update 已有 test 如有引用).

## Follow-up #5 — splash 5s hold pause env knob

**根因**: `tui_app.py:356` `await asyncio.sleep(5.0)` hardcode. user 想短一点 (e.g. 1s) / 长一点 都得改源码. Phase 19 Wave 7 follow-up Bug 3 加这 5s 是让 user 真看见 splash, 但有人有不同偏好.

**修法**: 加 env knob `LLM_SPLASH_PAUSE_S` default 5.0 (保 Wave 7 决策不破), env 覆盖. 加 validation (跟 `_read_read_timeout_env` 同 pattern, Phase 20.0 Task 1 follow-up 落地):
- non-float / negative → ValueError with env name in msg
- 0 → 允许 (用户主动设 skip hold)

**Files**: 
- `src/explain_engine/config.py` — 加 `_read_splash_pause_env() -> float` helper
- `src/explain_engine/chat/tui_app.py` — `_splash_lifecycle:356` 用 helper 替 hardcode 5.0

**Test**: 加 3 test in `tests/test_config_splash_pause.py`:
- `test_read_splash_pause_default_5`
- `test_read_splash_pause_env_override` 
- `test_read_splash_pause_invalid_raises`

## Follow-up #8 — /resume picker sessions sort by created_at desc

**根因**: `slash_commands.py:977-986` `_handle_resume` 无 args 路径, `metas = SessionStore().list()` 返 raw 顺序 (插入序), 传给 `SessionPickerScreen`. user 期望最近用的在顶 (跟 Finder Recent / Chrome 最近标签同语义).

**Note**: question >40 char 截断已 done (`tui_app.py:135`), 无需改.

**修法**: `_handle_resume` 内 metas 排序 `sorted(metas, key=lambda m: m.created_at, reverse=True)` 后再构 sessions_payload.

**Files**: `src/explain_engine/chat/slash_commands.py:968` (_handle_resume metas 拿到后).

**Test**: 加 1 test `tests/test_chat_slash_resume_hotfix.py::test_picker_sessions_sorted_by_created_at_desc` 或独立 file.
