## 4. 修复: textual 8.2.7 原生 `anchor()` 智能锚定

用户在 AskUserQuestion 选了**智能锚定**（滚到底跟随，但用户上翻则脱锚不被拽下）。
textual 8.2.7 `Widget.anchor()` 原生就是这个语义:

- `anchor()` (widget.py:800): "stay scrolled to the bottom when new content is added,
  **until the user moves the scroll position**"。
- 新内容跟随: compositor (`_compositor.py:609/693`) `if widget._anchored and not
  widget._anchor_released:` 自动滚到底。
- 用户上翻脱锚: PgUp/PgDn/scrollbar 走 `_scroll_to(release_anchor=True)` → 脱锚，
  **不依赖 mouse**（键盘滚动路径）。
- 翻回底部重锚: `_check_anchor()` (widget.py:823)。

**改动 (1 行 + 注释)**: `on_mount` 顶部 (splash/no-splash 分支前)：
```python
self.query_one("#output", VerticalScroll).anchor()
```
比预估的 ~15 行手写 `was_at_bottom` 更短更稳 (原生机制)。

4 行为在**真 app** headless 全验证 (`/tmp/probe_anchor.py`)：跟随到底 / 上翻脱锚 /
脱锚后不被拽下 / 回底重锚 + 经 `remove_children` (reset) 仍生效。

## 8. 后续 UX: 重开鼠标滚轮翻历史 (mouse=True)

auto-scroll 修好"输出到一半"主症状后, user 要**鼠标滚轮**回看历史 (`mouse=False`
当初为终端原生 click-drag 选字而关, 副作用是滚轮失效)。终端 mouse tracking 是
all-or-nothing — 滚轮事件 (button 64/65) 必须开 click tracking 才收得到, 无
"只收滚轮"模式 → 只能把 `repl_entry` 的 `run_async(mouse=False)` 反转为 `mouse=True`。

- **代价**: click-drag 原生选字被 app 抢走; 但 iTerm2 / macOS Terminal.app 按住
  **Shift / Option** 拖拽仍可原生选字复制。一行可回退 (`mouse=True` → `False`)。
- 保留 PgUp/PgDn 键盘滚动作不用鼠标的替代 (binding 不变)。
- test: `tests/test_repl_entry_mouse_enabled.py` (替换原 `test_repl_entry_mouse_disabled.py`,
  red→green 断言 `run_async(mouse=True)`)。
- [x] 真终端**滚轮** smoke: user 2026-05-29 确认"可以滚动了" ✓。

### 8.1 复制: textual 自带"选区感知" Ctrl+C (user 2026-05-29 实测确认)

mouse=True 后, textual 自己接管鼠标拖拽做**应用内文本选择** (拖选高亮, ALLOW_SELECT
默认 True, Static 可选). Ctrl+C 是**选区感知**的 — Screen 默认绑
`ctrl+c,super+c → screen.copy_text` (screen.py:272 / 985):
- **有选区**: `app.copy_to_clipboard(selection)` 走 OSC52 复制到系统剪贴板;
- **无选区**: `action_copy_text` `raise SkipAction()` 放行 → 落到本 app 的
  `ctrl+c → quit_app` 退出.

所以 **拖选 + Ctrl+C = 复制; 无选区 + Ctrl+C = 退出**, 自动并存, 不需 Option /
Cmd+C. (起初担心"本 app Ctrl+C 被 quit 占住, textual 复制用不了"是**错的** —
SkipAction fallthrough 让复制与退出共存.) user 实测确认 Ctrl+C 能复制 ✓.
banner 提示定为 `(滚轮翻历史; 鼠标拖选 + Ctrl+C 复制)` (test
`tests/test_tui_app_banner_hint.py`).

注意: 有选区时 Ctrl+C 是复制不是退出; 要退出先点一下取消选区或用 /quit.

`driver._enable/_disable_mouse_support` 切 tracking, guard `if not self._mouse`
