# 二、核心哲学

## 2.1 智能的本质

传统 AI：

```text

```

本系统：

```text
智能 = 概念演化能力
```

真正高级 cognition：

不是：

# 在已有概念上计算

而是：

# 形成新概念。

---

## 2.2 解释的本质

解释不是：

# 给出现象的语言描述。

而是：

# 对事件之间生成关系的压缩。

即：

```text
Explanation
=
Compressed Generative Structure
```

---

## 2.3 世界模型

世界不是静态 ontology。

而是：

# 动态生成系统。

因此：

系统不维护固定知识树。

而维护：

# evolving variable universe。

---

## 2.4 认知不是搜索

传统系统：

```text
question → search → answer
```

本系统：

```text

→ graph formation
→ mechanism stabilization
→ abstraction compression
→ insight emergence
```

## 2.5 高级认知的本质

真正高级 cognition：
